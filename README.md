# Proxy Manager

Расширение для Chrome: подключает прокси в один клик, скрывает реальный IP и следит, чтобы он не утёк мимо прокси.

## ✨ Возможности

-   🌐 **Прокси**: HTTP с логином и паролем, SOCKS5, SOCKS4
-   ⏻ **Один клик**: кнопка питания включает последний профиль, горячая клавиша **Alt+Shift+P** — тоже
-   🔎 **Проверка подключения**: внешний IP, страна и пинг через активный прокси
-   🛡️ **Защита от утечек**: WebRTC не раскрывает IP; предупреждение, если прокси не работает в инкогнито или его перехватило другое расширение
-   📋 **Быстрое добавление**: вставьте строку `user:pass@ip:port` — поля заполнятся сами
-   💾 **Импорт и экспорт**: списки в популярных форматах, превью до импорта, дубликаты пропускаются
-   🎨 **Интерфейс**: светлая и тёмная тема, поиск по профилям, удаление с возможностью вернуть

## 📦 Установка

1. Скачайте или клонируйте репозиторий
2. Откройте `chrome://extensions/`
3. Включите «Режим разработчика»
4. Нажмите «Загрузить распакованное» → выберите папку расширения
5. В «Сведениях» расширения включите **«Разрешить в режиме инкогнито»** — иначе в инкогнито-окнах Chrome не применяет ни прокси, ни защиту WebRTC. Popup напомнит об этом и даст ссылку на настройку

## 🚀 Использование

-   **Клик по профилю** — подключить
-   **Кнопка питания** — выключить прокси или включить последний профиль
-   **Alt+Shift+P** — то же самое без открытия окна (клавишу можно сменить в `chrome://extensions/shortcuts`)
-   **Клик по IP** — скопировать
-   **Наведение на профиль** — копировать строку, редактировать, удалить
-   **/** — поиск, когда профилей больше шести

Значок в панели: серый — прокси выключен, цветной — включён, на бейдже код страны выхода. Красный `!` — прокси перехватило другое расширение или политика.

### Форматы импорта

```
user:pass@ip:port
ip:port:user:pass
ip:port
socks5://ip:port
```

Схема в начале строки (`http://`, `socks5://`, `socks4://`) задаёт тип. Для строк без схемы тип выбирается в окне импорта. «Экспорт всех» копирует профили в том же формате.

## 🛡️ Защита

-   **WebRTC**: политика Chrome `disable_non_proxied_udp` — WebRTC ходит только через прокси и не раскрывает ни локальный, ни реальный IP. Звонки в браузере обычно продолжают работать через TCP. Включена по умолчанию.
-   **Проверка, что прокси действительно стоит**: если настройками прокси управляет другое расширение или политика, расширение не покажет «Подключено».
-   **Прокси не отвечает**: трафик не уходит напрямую — сайты просто не открываются, реальный IP остаётся скрытым.

## ⚠️ Ограничения Chrome

-   **SOCKS с логином и паролем не работает**: Chrome не умеет авторизацию для SOCKS. Используйте HTTP-прокси или доступ по IP.
-   **SOCKS4 резолвит DNS локально**: домены, которые вы открываете, видит ваш провайдер. Для анонимности берите SOCKS5 или HTTP.
-   **Пинг и флаги — только через активный прокси**: проверка неактивных шла бы напрямую с реального IP.

## 🔧 Технические детали

**Архитектура**: Manifest V3, Service Worker
**Права доступа**: proxy, storage, privacy, webRequest, webRequestAuthProvider, declarativeNetRequest (только чтобы удалить правила версии 1.1.1)
**Совместимость**: Chrome 108+

### Сборка для Chrome Web Store

```
node store/icons.js                                    # значки в icons/
node store/screens.js                                  # скриншоты 1280×800 и промо 440×280 в store/
powershell -ExecutionPolicy Bypass -File store\pack.ps1   # zip для загрузки
```

Скриптам нужен `puppeteer-core` и установленный Chrome. Скриншоты снимаются с настоящего popup с подставными данными (адреса из документационных диапазонов TEST-NET).
